# Chitraboli (চিত্রাবলী) ✨

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://chitraboli.lovable.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> **Handmade with Love, Crafted with Passion.** 

[Chitraboli](https://chitraboli.lovable.app/) is an elegant, modern e-commerce platform showcasing unique, handcrafted jewelry inspired by art, tradition, and passion. Designed with a sophisticated dark aesthetic, the platform offers a seamless shopping experience for premium artisan creations.

---

## 🌟 Features

*   **Premium Visual Showcase:** Beautiful dark-themed user interface optimized for high-quality jewelry photography.
*   **Dynamic Product Catalog:** Categorized jewelry collections including:
    *   **Clay Jewelry** (e.g., ["রংধনু" 🌈](https://chitraboli.lovable.app/product/4c9c2da4-7fe0-474e-93c5-f92910262f01), ["বীণা পলাশ" 🌿](https://chitraboli.lovable.app/product/d0f3422e-0809-46a1-9dad-e9bfa68085fd))
    *   **Bangles** (e.g., [Traditional Bangles](https://chitraboli.lovable.app/product/c1b994a7-2bdc-4220-a25c-f46a625060f5))
    *   **Rings, Necklaces, & Earrings**
*   **Interactive Shopping Cart:** Real-time cart management for a frictionless checkout experience.
*   **Order Tracking:** Built-in customer order verification and [tracking system](https://chitraboli.lovable.app/track-order).
*   **AI-Powered Shopping Assistant:** An integrated, multilingual [Chitraboli AI Assistant](https://chitraboli.lovable.app/) to answer customer queries instantly.
*   **Direct Support Integration:** Instant "Chat on WhatsApp" widget for quick inquiries and custom order discussions.

---

## 🛠️ Tech Stack

*   **Frontend Framework:** React (with TypeScript for robust type-safety)
*   **Build Tool:** Vite (for lightning-fast development and optimized production builds)
*   **Styling:** Tailwind CSS (utility-first styling framework)
*   **UI Components:** shadcn/ui & Radix Primitives (highly accessible, customizable components)
*   **Icons:** Lucide React

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) and **npm** (or **pnpm** / **yarn**) installed.

### Installation & Setup

1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/your-username/chitraboli.git](https://github.com/your-username/chitraboli.git)
   cd chitraboli

2. **Install Dependencies:**
   ```bash
   npm install
3. **Start the Local Development Server:**
   ````bash
   npm run dev
   
4. **Build for Production:**
   ```bash
   npm run build

## 📂 Project Structure

```text
├── src/
│   ├── components/     # Reusable UI components (buttons, inputs, cards)
│   ├── pages/          # Main application views (Home, Shop, Track Order, About)
│   ├── hooks/          # Custom React hooks
│   ├── context/        # State management providers
│   ├── lib/            # Utility functions and configurations (e.g., shadcn utils)
│   ├── App.tsx         # Main App router and layout wrapper
│   └── main.tsx        # React entry point
├── public/             # Static assets (logos, fallback images)
├── index.html          # HTML template
├── tailwind.config.js  # Tailwind CSS configurations
└── vite.config.ts      # Vite bundler configurations
```
